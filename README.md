# CineBlaze 🎬

A premium movie streaming webapp with stunning UI/UX, video playback, and seamless browsing experience.

## Features

- 🔥 Featured movies with parallax hero effect
- 🎥 Video player with quality selector
- ✨ Magnetic tilt cards with video preview
- 🏆 Cinema Hall of Fame
- ⌨️ Keyboard shortcuts (/, H, Esc)
- 📱 PWA support
- ♿ ARIA accessibility

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Vite
- TMDB API
- vidapi.xyz

## Getting Started

```bash
npm install
npm run dev
```
